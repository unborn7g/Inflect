# Demo video provenance

The narrated MP4 is a presentation of the working Inflect app and the supplied live-run evidence.

- Live-view scene: the builder's Windows app screenshot showing Presage landmarks and 1,128 samples.
- Review scene: the builder's actual completed live-session screenshot, corroborated by the exported session.
- Walkthrough scene: a real recording of Inflect running its labelled illustrated example. It uses example data and no camera measurement.
- Calibration scene: Inflect's original movement-guide illustrations.
- Narration: generated locally with the installed Microsoft Zira Desktop speech voice.
- Captions: generated from the narration script and burned into the video.

The video contains screenshots of the verified live run and a moving illustrated walkthrough. It does not contain a new continuous live-camera capture. The labels remain visible in the relevant scenes.

The public repo contains the functional native Presage integration, setup instructions and a summary of the completed live run. This video does not establish ASL accuracy, learning outcomes or sustained capture performance.

Camera keys and personal session identifiers are excluded from the video.
