# Publish Inflect on DEV

[Open the DEV editor](https://dev.to/new)

## Copy the article into DEV

1. Open the [article body ready to copy](https://raw.githubusercontent.com/unborn7g/Inflect/main/docs/dev-submission-body.md). Press **Ctrl+A**, then **Ctrl+C**.
2. Open the [DEV editor](https://dev.to/new) and sign in if needed.
3. Enter the title and add both tags below.
4. Click the article body field and paste with **Ctrl+V**. The copy above already excludes the title, tags and cover metadata.
5. Preview the article, check the demo and repository links, then publish from your DEV account.

**Title**

```text
Inflect: Let your face ask the question
```

**Tags**

```text
devchallenge, presagechallenge
```

Optional cover: [download the Inflect cover image](https://inflect-practice.vercel.app/assets/inflect-cover.jpg), then add it with DEV’s cover image control.
