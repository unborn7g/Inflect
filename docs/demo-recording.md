Builder credit: unborn. Target length: about two minutes. Use the actual desktop live mode.

The suggested pacing is an edit plan. Allow extra time for real camera startup and calibration; keep the full timed drill visible.

## Recording details

- Enter the key before recording the live part. For the consent-screen shot, use a blank input. Do not record a key reveal or the portal page.
- Keep Inflect visible during capture; hiding it stops the camera.
- Capture enough of the window to show the native live label, moving landmarks, cues and timer. Use Focus view if it makes the practice area easier to read.
- If the app voice works on your device, let viewers hear it during the drill and narrate before and after. Otherwise the written cues can demonstrate the same schedule.
- Use your real review, including gaps or low matching time. A matched duration is not an accuracy percentage.
- Cuts between setup stages are fine. Keep labels for any illustrated example, and use live mode for the core signal demonstration.
- Mention that longer hardware testing, learner evaluation and educator review are future work.

## Short video description

Inflect is a desktop studio for practising ASL brow cues with live Presage SmartSpectra landmarks, personal calibration and a 20-second timing review.

Built by unborn for the Presage SmartSpectra SDK Challenge.
Code: https://github.com/unborn7g/Inflect
Presage key required for live mode. Camera mirror and a labelled walkthrough are also available.
Facial-movement practice; educator review pending.
